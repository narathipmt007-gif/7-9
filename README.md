# เลข 7 ตัว 9 ฐาน V3 — อ้างอิง Meemodel

## ติดตั้ง GitHub Pages
1. สร้าง repository ใหม่
2. อัปโหลด `index.html` และ `README.md` ไปยัง root
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save
4. เปิด URL ที่ GitHub Pages แสดง

## สูตรฐานที่เพิ่ม
อ้างอิงคำอธิบายของ Meemodel:
- ฐาน 1 จากวันเกิด (อาทิตย์=1 ถึงเสาร์=7)
- ฐาน 2 จากเดือนเกิดตามปฏิทินไทย
- ฐาน 3 จากปีนักษัตรตามปฏิทินไทย
- ฐาน 4 ผลรวมฐาน 1–3 ในแนวดิ่ง ไม่ลดผลรวม
- ฐาน 5 ลดฐาน 4 ด้วย 7 จนอยู่ในช่วง 1–7
- ฐาน 6 = ฐาน 5 × 2 ลดด้วย 7
- ฐาน 7 = ฐาน 6 × 2 ลดด้วย 7
- ฐาน 8–9 ใช้ลำดับยามกลางวันและตำแหน่งหัว/ท้ายตามคำอธิบายที่พบในแหล่งออนไลน์

## เสวยอายุและแทรกอายุ
กำลังดาวตามภาพผู้ใช้: อาทิตย์ 6, จันทร์ 15, อังคาร 8, พุธ 17, เสาร์ 10, พฤหัสบดี 19, ราหู 12, ศุกร์ 21 รวม 108.
- ปีเสวย = กำลังดาวเสวย × กำลังดาวตัวเอง ÷ 108
- เดือนแทรก = กำลังดาวเสวย × กำลังดาวแทรก ÷ 108

## ข้อจำกัด
- Meemodel ระบุเปลี่ยนวัน 06:00 น. แต่ตามคำขอของผู้ใช้ โปรแกรมนี้ใช้ 00:00 น. และแจ้งความแตกต่างไว้ชัดเจน
- เดือนจันทรคติและปีนักษัตรต้องเลือกเอง เพราะแปลงอัตโนมัติอย่างถูกต้องต้องใช้ปฏิทินไทย 100 ปีและกฎเปลี่ยนปีนักษัตร
- ลำดับดาวเสวยอายุ/ดาวแทรกและวิธีแปลงเศษเป็นวันยังต้องยืนยันกับตำราต้นฉบับ
- ฐาน 8–9 ควรทดสอบเทียบตัวอย่างดวงจริงก่อนนำไปใช้จริง
- คำพยากรณ์เป็นข้อความทั่วไป ไม่ได้ผูกกับเลขแต่ละฐาน
